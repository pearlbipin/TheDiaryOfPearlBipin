Set up your pen

To write, you paste a GitHub token once. It's stored only in this browser. Every write after this is one click.

  1. Open github.com/settings/personal-access-tokens/new
  2. Token name: Diary write token
  3. Expiration: No expiration (or 1 year — your call)
  4. Repository access → Only select repositories → TheDiaryOfPearlBipin
  5. Permissions → Repository permissions → Contents: Read and write
  6. Generate token → copy it (starts with github_pat_)
